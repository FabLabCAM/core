# Validation de la version 0.6.1

Issue [#19](https://github.com/FabLabCAM/core/issues/19), 4 novembre 2026.

## Régression reproduite et corrigée

Dans 0.6.0, `delete(4294967297)` peut supprimer la forme 1. Une valeur négative
congruente et les tableaux présentent le même défaut. Les tests moteur et CLI
ont échoué avant correction : référence tronquée, script accepté et sortie créée.
Ils réussissent après la conversion contrôlée commune aux deux entrées de l’API.

- 120 combinaisons : dix fonctions, six valeurs hors plage et deux formes
  d’argument (entier seul/tableau mixte). Valeur fautive et ligne vérifiées.
- Entiers négatifs, dépassement `u32`, extrêmes `i64`, bornes numériques et
  identifiants existants, références absentes et types non entiers.
- Une création et un déplacement avant l’erreur ne modifient ni le projet ni
  les historiques Annuler/Rétablir. Un rétablissement préexistant reste utilisable.
- Test du véritable processus CLI : code 1, erreur lisible, entrée inchangée,
  sortie non créée, sortie préexistante non écrasée, même si elle est l’entrée.
- Sur macOS Apple Silicon : **364 tests workspace réussis**, Clippy tous targets
  avec `-D warnings`. Aucun changement de dépendances ni de format.

## Exemples documentés

La CLI 0.6.1 exécute `plaque.rhai` : 21 formes, quatre opérations, puis un programme
de 1 947 lignes. Le nouvel exemple `identifiant-invalide.rhai` est refusé à la
ligne 3, sans fichier de sortie. Les trois rapports machine du guide ont été
régénérés : états valide/invalide/incomplet et codes 0/1/2 inchangés.

## Distribution et interface

Avant publication, les six cibles natives doivent réussir tests, construction et
contrôles de paquet ; les douze archives/installateurs doivent être vérifiés.
Le contrôle du paquet installé, la capture du refus dans l’éditeur Rhai et les
résultats CI sont consignés dans le [guide Rhai](https://fablabcam.github.io/docs/reference/rhai/)
et la [release](https://github.com/FabLabCAM/core/releases/tag/v0.6.1).
Ce document décrit la validation source et ne présume pas le résultat de ces
contrôles de distribution. Aucun usinage physique n’est effectué.
