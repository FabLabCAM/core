# Validation 0.7.0 — assistant natif

## Sources et protocoles

- macOS Apple Silicon, Rust 1.99.1 ; tests workspace et Clippy avec `--locked`.
- Tests locaux des quatre protocoles : SSE Responses/Claude/Mistral, NDJSON Ollama,
  appels d’outils fragmentés, retour natif du résultat, erreurs HTTP, flux incomplet,
  outil inconnu, arrêt, filtrage de contexte et absence de secret sérialisé.
- Tests métier : modes, lots atomiques, valeurs invalides, proposition obsolète,
  script édité/exécuté séparément, limites Rhai, caisson et séparation, outillage,
  exports distincts. Tests du pont UI : annuler/rétablir dessin+script+meuble,
  changement de sélection/fournisseur et continuité entre pages.

## Service réel

Mistral, `mistral-small-latest`, 2026-11-04 : streaming, caisson 600 × 400 × 800 mm,
18 mm, deux tablettes et dos (7 panneaux), division (8 panneaux), Plan éditant
Rhai sans exécution, Agent exécutant un cercle, création/duplication d’outils,
question sur simulation partielle à 58 %, restitution native du résultat d’outil.
Suite `assistant_live` réussie. Projets synthétiques ; aucun secret dans les logs.

OpenAI, Claude et Ollama : tests de protocole locaux seulement. Aucune clé pour
les deux premiers et aucun modèle Ollama installé lors de cette validation.
L’issue #20 reste ouverte pour la qualification réelle restante.

## Interface et distribution

La validation de l’interface et des paquets est consignée avec les résultats
finaux avant publication. Les captures utilisateur proviennent de l’application
réelle sur macOS Apple Silicon, avec des projets synthétiques publics.
La simulation 2.5D et les exemples d’outils ne qualifient aucune machine réelle.
