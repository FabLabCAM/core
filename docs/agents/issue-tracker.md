# Suivi des demandes

Les spécifications et critères d'acceptation sont dans les issues de
https://github.com/FabLabCAM/core/issues. Préférer le connecteur GitHub ; `gh issue
view <numéro> --repo FabLabCAM/core --json title,body` est le repli CLI.

Pour la version 0.6.0, la référence est l'issue #17, y compris son complément
sur les assemblages. Ne fermer qu'après publication et vérification des critères,
conformément à ../releasing.md. Le guide vit dans FabLabCAM/docs.
