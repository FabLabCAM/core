# Sécurité

Signaler les vulnérabilités de manière privée avec la fonction « Report a
vulnerability » dans l'onglet Security du dépôt :
https://github.com/FabLabCAM/core/security/advisories/new

Inclure la version, les étapes de reproduction, le résultat attendu et l'impact.
Ne pas publier de secrets ou de données personnelles dans une issue publique.

Les corrections sont intégrées sur la branche principale. Le projet est en
phase initiale et ne garantit pas de délai de réponse ni de maintenance des
anciennes versions.

Les fichiers de dessin et scripts sont des entrées non fiables. Les scripts
Rhai exécutent des actions sur le document ; ouvrir uniquement des scripts dont
le contenu a été vérifié. Vérifier les trajectoires avant un usinage réel.
